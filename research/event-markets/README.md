# Event-market prior work and differentiation

Reviewed 30 September 2026. Named systems are primary-source precedents, not measured live comparisons.

| Mechanism | Established capability | What remains unestablished for Asce |
|---|---|---|
| Shared Gnosis CTF condition | Complete partitions and atomic contingent claims; arbitrary finite nonnegative curves are replicated by baskets | A new mathematical backing advantage |
| Polymarket negative risk | Contractual conversions across declared exclusive outcomes | General exact support for every custom scalar curve |
| Polymarket Combo collateral return | Decompose compatible exposure, merge complements, retain residuals | That a restricted old-adapter comparison covers current platform behavior |
| Kalshi collateral return | Eligible exclusive/directional event groups release guaranteed payouts early | Live funded-exit behavior and exact equivalence to arbitrary Asce account operations |
| DIVA | Configurable paired contingent position creation | Account-wide clearing across multiple separate pool liabilities |

Sources: [CTF guide](https://conditional-tokens.readthedocs.io/en/latest/developer-guide.html), [Polymarket negative risk](https://docs.polymarket.com/concepts/negative-risk), [Combo collateral return](https://docs.polymarket.com/trading/combos/collateral-return), [Kalshi collateral return](https://help.kalshi.com/en/articles/13823816-collateral-return), [DIVA creation guide](https://docs.divaprotocol.io/diva-app/create-position-tokens).

Kalshi's documentation also cautions that early returned collateral can restrict sales, and describes event-level eligibility being fixed when an order is first placed. That suggests a concrete operation to compare, but this review did not execute an authenticated Kalshi portfolio exit. It is not proof Asce can deliver a better actual quote or unlock behavior.

Many payoff shapes need not mean many independent liquidity pools. Normalize them into a small common basis; quote portfolios from shared inventory; route between economically equivalent funded baskets. These are useful product choices, not unprecedented finance.

Potential differentiation is reusable custom curves plus inexpensive exact account changes and understandable bounded exposure. It must win a recurring task against a capable CTF implementation or a named venue, after fees, spreads, funding checkpoints and finality delays. Capital savings against unrelated binary pools alone do not establish the business.

This research intentionally excludes cross-event Combo risk offsets. Polymarket's broader documented capabilities are mentioned to delimit novelty claims, not imported into Asce's allowed margin domain.
